# Honestly Hub · Honestly TUN

Приложение на C# для Windows 10/11 x64: встроенный VPN, переключение VPN ↔ Zapret, сохранённые профили Epic Games и музыкальная панель Spotify. Текущая версия — **2.4.11**.

<img src="Design/icon-circle-v2.png" width="96" alt="Honestly TUN">

## Скачать и запустить

Скачайте **HonestlyTUN-2.4.11-windows-x64.zip** со страницы [Releases](https://github.com/pe4enka2728-ui/Honestly-Hub/releases). Архивы «Source code» содержат исходники, а не готовую программу.

1. Установите [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0).
2. Распакуйте ZIP целиком. Сохраните папки `App`, `Runtime` и `ThirdParty` рядом друг с другом.
3. Запустите `App\HonestlyTUN.exe`. Для TUN и управления Zapret программа запрашивает права администратора.
4. Добавьте собственную подписку и выберите сервер. Для Zapret укажите путь к его установленной папке.

INCY, Zapret, Epic Games Launcher и Spotify в архив не входят. **При закрытии Honestly TUN встроенный VPN отключается.**

## Возможности

- Встроенный VPN по персональной HTTPS-подписке, ссылкам VLESS, VMess, Trojan, Shadowsocks или JSON Xray; выбор DNS и сервера.
- Альтернативный внешний клиент INCY; переключение VPN ↔ Zapret, отдельное включение и состояние каждого компонента.
- Два режима Zapret: запуск стратегии `.bat` и установка через меню `service.bat`.
- Spotify: обложка, управление воспроизведением, спектр звука, очередь и полноэкранный плеер. Для фоновой синхронизации громкости используются Spotify Premium и привязка через OAuth PKCE.
- Список приложений с иконками и состоянием, панель персонажей ThatPet, заставка и плавная прокрутка.
- Локальные профили Epic Games: сохранение, импорт/экспорт, переключение с восстановлением данных, проверка входа, добавление указанного друга с сохранённых аккаунтов и таймер 48 часов после полного обхода.

Пароли Epic не запрашиваются. Первичный вход и повторный вход после отзыва авторизации выполняются вручную в официальном лаунчере с «Запомнить меня». Автоматизация друзей зависит от интерфейса и OCR Epic; начните с кнопки «Проверить поиск». Подробности — [Epic Games](docs/EPIC-ACCOUNTS.md).

## Сборка из исходников

Нужны Windows, .NET SDK 10 с Windows Desktop и доступ к NuGet при первом восстановлении пакетов.

```powershell
.\build.ps1
```

Результат появится в `App`. Для встроенного VPN возьмите папку `Runtime` из готового релиза и поместите её рядом с `App`: исполняемые файлы ядер хранятся в релизе, а не в Git. В репозитории находятся их версии, контрольные суммы, лицензии и архивы исходников в `ThirdParty`.

Проверки переключения, подписок, анимации, аудио и операций с профилями Epic на тестовых данных:

```powershell
.\build.ps1 -RunChecks
```

UI-проверки в `UiTests` и `PetTests` запускаются отдельно; они могут открывать окна и обращаться к локальным настройкам. Обычная сборка их не запускает.

## Данные и настройки

Личные подписки, профили, OAuth-токены и журналы в публикацию не входят. `App\settings.json` создаётся при работе программы. Чувствительные локальные хранилища находятся в `%LOCALAPPDATA%\HonestlyTUN` и защищены Windows DPAPI для текущего пользователя. Они не предназначены для публикации или переноса на чужой компьютер.

Spotify привязывается собственным Client ID с Redirect URI `http://127.0.0.1:43879/callback/`. Client Secret программе не нужен. Персональную ссылку VPN вводите только в приложении.
