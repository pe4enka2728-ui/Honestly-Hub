# Подготовка публикации 2.4.11

Публикация содержит исходники Honestly TUN, медиа, тестовые проекты, сторонние лицензии и отдельный архив готовой программы для Windows x64.

Из публикуемых исходников удалены абсолютные пути к машине разработчика. Конфигурация пользователя, хранилища VPN и Epic, OAuth Spotify, диагностические снимки, журналы, каталоги инструментов и промежуточные сборки не включены. Отдельный файл ThatPet/LICENSE.txt убран по запросу владельца; его исходные уведомления и условия сохранены в ThirdParty/NOTICE.md.

Проверки публикации, размер архива и SHA-256 перечисляются в описании релиза на GitHub. Контрольные суммы исполняемых файлов VPN-ядер находятся в Source/CoreHashes.json. Исходники точных версий ядер включены в ThirdParty.

Приложение не запускалось для сетевой проверки при подготовке публикации. Реальные аккаунты Epic не переключались, заявки друзьям не отправлялись. Для проверки на конкретной системе используйте USER-CHECKS.md и VPN-CHECKS.md.
