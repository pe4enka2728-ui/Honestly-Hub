# Медиа Honestly TUN 2.3

- icon-circle-v2.png — круглая чёрная иконка с прозрачными внешними углами, текущий вариант.
- icon-preview-v2.png — предпросмотр текущей иконки в нескольких размерах.
- icon-rounded-v1.png и icon-preview.png — предыдущий вариант со скруглённым квадратом, оставлен для сравнения.
- intro-transparent-frame.png — отдельный кадр с настоящим alpha-каналом.
- intro-preview.png — шесть кадров на цвете фона приложения; это предпросмотр, не скриншот запущенной программы.

Анимация получена из присланного пользователем видео. Шахматный фон и нейтральная серая тень удалены по цветовому отличию от красных элементов; сохраняются движение и полупрозрачные края. В приложении используются PNG RGBA из Media/intro.frames.zip. Звук отсутствует. Исходный пользовательский ролик не изменён.

В 2.2.1 кадры подготовлены из исходного разрешения 1280×720, без уменьшения до 848×477. Выполнено мягкое повышение чёткости alpha-краёв. Превью на ровном фоне предназначено для проверки медиа: в приложении анимация располагается поверх затемнённого живого интерфейса.

В 2.3 немного повышена чёткость alpha-краёв при тех же 1280×720. Подписи/обложки Spotify в превью сборки не включены.
